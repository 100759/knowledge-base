# 常见问题

## 文章发布后多久能上线？

通常在点击「发布」后 1-2 分钟内，GitHub 会完成代码提交并触发自动构建部署。你可以在 GitHub 仓库的 Actions 页面查看构建进度。

## 忘记了后台地址怎么办？

后台地址就是你的站点域名加上 `/admin/`。例如：
- 站点地址：`https://your-site.edgeone.app`
- 后台地址：`https://your-site.edgeone.app/admin/`

## 可以在手机上编辑吗？

可以！后台管理界面支持响应式设计，在手机浏览器中也能正常使用。但建议在电脑上编辑长篇文章，体验更好。

## 文章支持哪些格式？

- Markdown 语法（标题、列表、代码块、引用等）
- 图片插入（自动上传到仓库）
- 富文本编辑（加粗、斜体、链接等）

## 如何修改站点名称？

站点名称等配置需要修改源码文件。如需修改，请联系搭建此站点的人。

## 部署失败怎么办？

1. 检查 GitHub 仓库的 Actions 日志
2. 确认文章内容没有语法错误
3. 确认文件名没有特殊字符
4. 如果问题持续，可以尝试重新发布文章
