# 知识库介绍

欢迎来到你的个人知识库！这是一个基于 **VitePress** 和 **Decap CMS** 构建的静态文档站点，支持在线内容管理。

## 功能特点

- **在线编辑**：通过 `/admin/` 后台直接管理文章，无需写代码
- **全文搜索**：左上角搜索框可搜索所有文章内容
- **暗黑模式**：点击右上角图标切换浅色/深色主题
- **响应式设计**：手机、平板、电脑均可完美访问
- **自动部署**：后台保存文章后，自动构建并部署到线上

## 如何开始

1. 访问 [管理后台](/admin/) 登录
2. 点击「知识文章」或「使用指南」
3. 点击「新建」按钮创建文章
4. 填写标题、选择分类、编写正文
5. 点击「发布」即可上线

## 站点结构

| 目录 | 说明 |
|------|------|
| `/` | 首页 |
| `/guide/` | 使用指南 |
| `/articles/` | 知识文章 |
