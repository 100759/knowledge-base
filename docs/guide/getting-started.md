# 快速上手

## 发布第一篇文章

1. 打开浏览器，访问站点的 `/admin/` 路径
2. 使用 GitHub 账号登录
3. 在左侧选择「知识文章」
4. 点击右上角「新建 文章」
5. 填写以下内容：
   - **标题**：文章标题
   - **描述**：一句话概括（可选）
   - **分类**：选择合适的分类
   - **标签**：添加标签（可选）
   - **正文**：使用富文本编辑器或 Markdown 编写内容
6. 点击右上角「发布」按钮

文章发布后，GitHub 仓库会自动收到提交，触发自动构建部署。大约 1-2 分钟后，新文章就会出现在站点上。

## 编辑已有文章

1. 在后台左侧选择对应的集合（如「知识文章」）
2. 在列表中找到要编辑的文章
3. 点击文章标题进入编辑
4. 修改内容后点击「发布」
5. 系统会自动提交更改到 GitHub，触发重新部署

## 删除文章

1. 在文章列表中找到要删除的文章
2. 点击文章进入编辑页面
3. 点击右上角「删除」按钮
4. 确认删除即可

## 富文本编辑器说明

Decap CMS 的 Markdown 编辑器支持两种模式：

- **富文本模式**：所见即所得，类似 Word 编辑体验，适合不熟悉 Markdown 语法的用户
- **Markdown 模式**：直接编写 Markdown 源码，适合熟悉 Markdown 的用户

点击编辑器右上角的切换按钮可以在两种模式间切换。

## 插入图片

1. 在编辑器中，将光标放在要插入图片的位置
2. 使用编辑器工具栏的图片按钮，或直接拖拽图片到编辑器
3. 图片会自动上传到 GitHub 仓库的 `docs/public/images/` 目录
4. 图片会在文章中自动显示
