# 欢迎来到知识库

这是你的知识库的第一篇文章。这个知识库使用以下技术构建：

- **VitePress**：Vue 生态的静态文档站点生成器，速度快、体验好
- **Decap CMS**：基于 Git 的内容管理系统，支持网页端管理文章
- **EdgeOne Pages**：腾讯云的静态站点托管服务，全球加速

## 你可以做什么

1. **写文章**：访问 `/admin/` 后台，直接在网页上编写文章
2. **分类管理**：为文章设置分类和标签，方便组织内容
3. **全文搜索**：使用站点搜索功能快速查找内容
4. **暗黑模式**：在浅色和深色主题之间切换

## 开始你的第一篇文章

1. 点击导航栏的「管理后台」链接
2. 使用 GitHub 账号登录
3. 选择「知识文章」
4. 点击「新建 文章」
5. 编写内容并发布

就这么简单！发布后文章会自动出现在这个站点上。
