待完成步骤 需要操作

站点已部署，但后台管理（/admin/）需要完成以下 OAuth 配置后才能使用：

第一步：创建 GitHub OAuth 应用

1打开 https://github.com/settings/developers

2点击「New OAuth App」

3填写以下信息：

  • Application name：知识库后台
  • Homepage URL：https://knowledge-base-mlyw2k7r.edgeone.cool
  • Authorization callback URL：暂时填 https://knowledge-base-mlyw2k7r.edgeone.cool（后面部署 Worker 后会更新）

4创建后，记录下 Client ID

5点击「Generate a new client secret」，生成并记录下 Client Secret

第二步：部署 Cloudflare Worker（OAuth 代理）

Decap CMS 需要一个服务器端代理来处理 GitHub OAuth 认证。我们使用 Cloudflare Workers（免费）来实现。

1注册/登录 Cloudflare（免费）

2进入左侧菜单「Workers & Pages」

3点击「Create」→「Create Worker」

4给 Worker 起个名字，如 decap-oauth，点击「Deploy」

5部署后点击「Edit code」，删除编辑器中的所有默认代码

6打开项目仓库中的 oauth-worker/worker.js 文件，复制全部内容粘贴到编辑器中

7点击右上角「Deploy」保存

8进入 Worker 的「Settings」→「Variables」

9添加两个环境变量：

  • GITHUB_CLIENT_ID = 第一步获取的 Client ID
  • GITHUB_CLIENT_SECRET = 第一步获取的 Client Secret

10保存后，记录下 Worker 的 URL，格式类似：https://decap-oauth.xxx.workers.dev

第三步：更新 GitHub OAuth 回调地址

1回到 GitHub OAuth 应用设置页面

2将 Authorization callback URL 改为你的 Worker URL：https://decap-oauth.xxx.workers.dev

3保存

第四步：告诉我 OAuth 信息

这一步你不需要改任何文件！

把以下两个信息发给我（在对话中回复即可）：

  1. GitHub OAuth App 的 Client ID
  2. Cloudflare Worker 的 URL（如 https://decap-oauth.xxx.workers.dev）

我会自动更新配置文件并重新部署站点。

日常使用指南 配置完成后

如何发布新文章

  1. 打开后台管理地址：https://你的域名/admin/
  2. 使用 GitHub 账号登录
  3. 在左侧选择「知识文章」或「使用指南」
  4. 点击右上角「新建 文章」按钮
  5. 填写标题、选择分类、添加标签
  6. 在正文编辑器中编写内容（支持富文本和 Markdown 两种模式）
  7. 点击右上角「发布」按钮
  8. 等待 1-2 分钟，文章自动出现在站点上

如何修改已有文章

  1. 打开后台管理地址
  2. 在左侧选择对应的分类
  3. 在文章列表中找到要修改的文章，点击进入
  4. 修改内容后点击「发布」
  5. 等待自动部署完成

如何删除文章

  1. 在文章列表中找到要删除的文章
  2. 点击文章进入编辑页面
  3. 点击右上角「删除」按钮
  4. 确认删除

富文本编辑器使用

Decap CMS 的 Markdown 编辑器支持两种模式切换：

  • 富文本模式：所见即所得，类似 Word，适合不熟悉 Markdown 的用户
  • Markdown 模式：直接编写 Markdown 源码，适合熟悉语法的用户

点击编辑器右上角的切换按钮即可在两种模式间切换。

插入图片

  1. 在编辑器中，将光标放在要插入图片的位置
  2. 使用工具栏的图片按钮，或直接拖拽图片到编辑器
  3. 图片会自动上传到 GitHub 仓库
  4. 图片会在文章中自动显示

设置永久访问（推荐）

当前站点地址带有临时认证参数，有效期约 3 小时。要设置永久访问：

1登录 腾讯云 EdgeOne 控制台

2找到项目「knowledge-base」

3在项目设置中，可以：

  • 绑定自定义域名（如 kb.yourdomain.com）
  • 或关闭访问认证，使站点公开可访问

4设置完成后，使用新域名访问站点和后台

设置 GitHub 自动部署（推荐）

当前部署是手动触发的。设置 GitHub 自动部署后，每次 Decap CMS 保存文章（即 push 到 GitHub），都会自动触发构建部署：

1登录 EdgeOne 控制台，找到项目「knowledge-base」

2在「构建部署」或「Git 集成」设置中，连接 GitHub 仓库 100759/knowledge-base

3配置构建设置：

  • 构建命令：npm install && npm run build
  • 输出目录：docs/.vitepress/dist

4保存后，每次 push 代码到 main 分支都会自动构建部署

技术架构

  • 前端框架：VitePress v1.6.4（Vue 生态静态文档生成器）
  • 后台 CMS：Decap CMS v3.4.0（Git-based 内容管理）
  • 代码托管：GitHub（100759/knowledge-base）
  • 部署平台：EdgeOne Pages（腾讯云）
  • OAuth 代理：Cloudflare Workers（免费）
  • 侧边栏：自动生成，新增文章后自动出现在导航中
  • 搜索：VitePress 内置本地全文搜索
  • 暗黑模式：VitePress 内置，支持手动/自动切换
